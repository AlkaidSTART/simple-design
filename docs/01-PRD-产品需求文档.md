## 1. 产品定位

### 1.1 一句话定位

> 为设计师与设计爱好者打造的「**能产出真代码、真资产**」的低门槛设计工作台——从灵感、界面原型到可交付代码与导出资源的一站式出口。

**关键词**：轻、快、可交付、有面子（作品集）、有回报（模板/资产变现）。
**核心洞察**：用户要的不是「更强的画布」，而是「**最快的从想法到可交付成品**」。我们卖的是**结果**，不是工具本身。

### 1.2 差异化修正（采纳首席批判官意见）

| 原假设 | 批判结论 | 修正后立场 |
|---|---|---|
| 为设计师做「低代码」 | 设计师天生会代码级控制，低代码是能力降级版 | ✅ 目标从「低代码」转向「**AI 原生生成 + 一键交付**」 |
| 黑白+毛玻璃是新潮差异化 | 审美赌博；低端 pad 掉帧、对比度不足（WCAG） | ✅ 降级为「**视觉主题选项**」，做渐进增强 + 降级开关 + 晨昏双模式 |
| pad/手机优先 == 趋势 | 设计工具主场在桌面端（像素密度/快捷键/多屏） | ✅ **桌面端为主力编辑，移动端做浏览/轻编辑/分享** |
| 免费订阅为主变现 | 目标用户习惯了 Figma 免费心智，纯订阅难 | ✅ 改「**免费钩子(AI 生成) + 导出付费 + 市场抽成**」三层模型 |

**真正的差异化（三条之一，取其一为主）**：
1. **AI 原生生成**（输入文案/品牌色 → 生成可编辑设计系统 → 一键导出 React/Vue/HTML + Tailwind）——**首选主线**
2. 模板/设计资产交易市场的网络效应——**次选（v2.0 生态）**
3. 极窄垂直场景（电商详情页 / 中小团队 Style-token 管理）——**备选**

### 1.3 目标用户与痛点

| 层级 | 画像 | 付费意愿 | 核心诉求 |
|---|---|---|---|
| **P0** | 设计爱好者/入门学习者（学生、转行、被 Figma 劝退） | 低但量大 | 免费牵引、快速出作品 |
| **P1** | 独立设计师/自由职业者（接私单、快速提案） | **高（核心付费层）** | 交付可落地 HTML、快 |
| **P2** | 小团队/微型工作室 | 中高 | 模板库共享、品牌统一 |
| **P3** | 内容创作者/自媒体（海报、封面、落地页） | 低、高频导出 | 不用复杂工具 |

**核心痛点（按解压价值排序）**：
1. 会设计不会写代码：创意成型后无法变成可用页面（**交付断层**）
2. 专业工具太重：Figma 学习曲线陡、功能过载
3. 产出难落地：设计稿到前端还原成本高、改稿往返耗时
4. 缺可复用资产：没有组件/模板沉淀，每次从零开始
5. 作品集无输出物：学了很久拿不出「能打开看」的成品
6. 导出碎片化：PNG/HTML/图标/字体各要一套工具

## 3. 功能范围

### 3.1 MVP（v1.0）必须

| 模块 | 功能 | 优先级 |
|---|---|---|
| 画布 | 拖拽、缩放（0.1x–4x 以指针为中心）、平移、框选、图层、网格、一键自适应 | P0 |
| 元素系统 | 常用组件库（按钮/卡片/布局/文本/图片） | P0 |
| 视觉系统 | 黑白+毛玻璃主题预设（**含降级开关 + 晨昏双模式**） | P0 |
| **导出** | **PNG / HTML（单页）/ ZIP 资源包**（MVP 关键闭环） | **P0** |
| **AI 生成（种子版）** | **文本/品牌色 → 生成设计稿骨架（v1.0 先做「模板即种子」轻量版，v1.1 上真模型）** | P0（方向性占位） |
| 模板库 | 20+ 内置模板（首页/落地页/海报） | P0 |
| 账号与云存储 | 登录、云保存、自动保存（本地草稿优先） | P0 |

### 3.2 后置（v1.1 → v2.0）

- **v1.1**：AI 文本转页面（真模型）、自定义组件库、协作共享链接、SVG/PDF/React 代码导出
- **v1.2**：团队席位、版本历史、可复用「设计系统」
- **v2.0**：UGC 模板交易市场、第三方接入

### 3.3 明确不做

- ❌ 完整 Figma 级矢量/原型功能
- ❌ 实时多人协同（MVP 成本高、价值未验证；v1.0 预留 Yjs 接入点）
- ❌ 自研渲染引擎（v1.0 用 html2canvas-pro，预留 IRenderer 接口）
- ❌ 服务端导出（导出永远客户端优先，成本第一优化杠杆）

## 4. 关键交互流程

### 4.1 核心闭环（北极星流程）

```
注册/进入 → 选择模板或从空白开始 → 拖拽/AI 生成设计
  → 编辑属性（位置/尺寸/颜色/文本） → 预览 → 导出 PNG/HTML/ZIP → 下载交付
```

### 4.2 画布交互约定（对齐 Figma）

| 操作 | 行为 |
|---|---|
| Ctrl/Cmd+滚轮 | 以鼠标为中心缩放 |
| 滚轮/双指 | 平移 |
| 中键/空格+拖拽 | 平移 |
| Shift+1 / Shift+0 | 适配画板 / 100% |
| 触控板捏合 | 缩放（移动端） |
| 选中元素拖拽 | 移动元素 |
| 空白处拖拽 | 平移画布 |

### 4.3 导出触发与付费点

| 导出类型 | 免费档 | Pro 档 |
|---|---|---|
| PNG | 带水印 | 无水印 + 2x 高清 |
| HTML | ✗ | ✓ 独立单文件 |
| ZIP 资源包 | ✗ | ✓ 含 preview.png + manifest |

**变现原则**：免费给「能玩」，导出真 HTML/无水印触发「想付费」——**导出即付费点**。

## 5. 数据模型（核心实体）

> 完整 Zod schema 见《04-整体架构文档》§4；此处为业务视角。

```
Document { id, name, artboards[], viewport(会话级), createdAt, updatedAt, version }
Artboard { id, name, width, height, background, x, y, layers[] }
Layer { id, type(rect|text|image|group), name, x, y, width, height,
        rotation, opacity, visible, locked, parentId, zIndex }
```

**原则**：纯数据、可序列化、可版本化；世界坐标 + 像素单位；扁平数组 + parentId 组织层级；前后端共享 Zod schema 校验。

## 6. 非功能需求

### 6.1 性能基线（回归门禁）

| 指标 | 基线 |
|---|---|
| 画布拖拽帧率 | 桌面 ≥50fps，手机 ≥35fps |
| 拖拽首帧延迟 | <16ms |
| 缩放重渲染（100 元素） | <60ms |
| 导出 PNG（100 元素） | <2s |
| 大画布冷启动（500 元素） | <4s（P2） |

### 6.2 兼容性

- Viewport：手机 375×667 / pad 1024×768 / 桌面 1920×1080 / 折叠屏 344×882
- 浏览器：Chromium（最新+上一版）、Safari、Firefox ESR（功能级）
- 触控：`touch-action:none` 断言（pinch 不触发页面缩放、单指不触发原生滚动）；dpr 1/2/3 渲染与导出分辨率；`env(safe-area-inset)` 安全区适配
- **毛玻璃降级**：低端 pad/鸿蒙/Android WebView backdrop-filter 支持残缺 → 必须有运行时降级开关（feature flag）

### 6.3 可访问性

- 黑白主题需满足 WCAG AA 对比度（**含晨昏双模式**，暗色下对比度自动校验）
- 键盘可达性：工具栏/属性面板可 Tab 导航（桌面端）

## 10. 验收标准（出口门禁）

### 10.1 产品验收

- [ ] 核心闭环可跑通：拖拽编辑 → 导出 HTML/ZIP → 用户愿意付费（内测验证）
- [ ] 导出产物与画布视觉一致（PNG diff < 阈值，HTML/ZIP 清单完整）
- [ ] 自动保存 debounce + flush，刷新可恢复
- [ ] 毛玻璃降级开关 + 晨昏双模式可运行时切换
- [ ] 桌面端 ≥50fps 拖拽帧率，移动端 ≥35fps

### 10.2 技术验收（QA 出口门禁，P0）

- [ ] zoomAt 锚点稳定性 ±0.1px（连续缩放回环）
- [ ] hit-test 层级遮挡 + 旋转图层命中准确
- [ ] schema 严格/宽松双模式 + v1→v2 迁移快照
- [ ] PNG diff < 0.5%；HTML/ZIP 无路径穿越、CRC 通过
- [ ] 核心拖拽/缩放 E2E 在 Chromium+WebKit 绿
- [ ] 性能回归门禁无劣化（≥2σ 告警）
