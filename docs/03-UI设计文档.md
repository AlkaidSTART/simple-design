> 版本：v1.0（归一化基线）｜ 日期：2026-08-06
> 来源：产品定位与技术变现 v1.0（界面质感/品牌）+ 全栈架构 v0.1（视觉规范）+ 首席批判与创新评审 v1.0（降级与对比度修正）归一化

## 1. 设计目标与原则

### 1.1 设计语言一句话
> **克制、高级、可靠、懂设计师的「懒人美学」**——工具感 + 高级感，成品即作品。

### 1.2 设计原则
1. **结果导向**：一切 UI 围绕「尽快导出真交付物」——导出入口永远可达（顶部常驻）
2. **渐进增强**：毛玻璃是增强项而非必需品，低端设备自动降级不破版
3. **触屏与桌面双模式**：桌面三栏完整工作台；移动端紧凑悬浮工具栏 + 单指拖画布
4. **对比度合规**：晨昏双模式均满足 WCAG AA
5. **动效克制**：微动效体现质感，不干扰操作

### 1.3 品牌

| 项 | 内容 |
|---|---|
| 名字方向 | *GlassStudio / BlankCanvas / MonoFlow / GlassNote* |
| Slogan | **设计即成品 — "From idea to deliverable."** |
| 人格 | 克制、高级、可靠、懂设计师 |

## 2. 视觉规范

### 2.1 色板（黑白灰主调）

| Token | 亮色（晨） | 暗色（昏） | 用途 |
|---|---|---|---|
| `--ink` | #0a0a0a | #fafafa | 主文本/主按钮 |
| `--paper` | #fafafa | #0a0a0a | 背景基底 |
| `--surface` | rgba(255,255,255,.62) | rgba(17,17,19,.55) | 玻璃面板底 |
| `--surface-border` | rgba(0,0,0,.08) | rgba(255,255,255,.09) | 玻璃描边 |
| `--text-primary` | #18181b | #fafafa | 一级文本 |
| `--text-secondary` | #52525b | #a1a1aa | 二级文本 |
| `--text-tertiary` | #71717a | #8b8b94 | 三级文本/标签 |
| `--canvas-bg` | #efefef（点阵） | #121214（点阵） | 画布区 |
| `--glass-blur` | blur(22px) saturate(150%) | blur(22px) saturate(150%) | 毛玻璃模糊 |

> ⚠️ 对比度要求：`--text-secondary` 在亮/暗玻璃背景上均需通过 WCAG AA（正文 ≥4.5:1，大文本/标签 ≥3:1）——暗色玻璃底 (17,17,19,.55) 上 `#a1a1aa` 对比度 ≈ 7:1 ✅；亮色玻璃底上 `#52525b` ≈ 5.8:1 ✅。**新增颜色必须过对比度检查**。

### 2.2 玻璃组件规范（渐进增强）

```css
.glass{
  background:rgba(255,255,255,.62);
  border:1px solid rgba(0,0,0,.08);
  backdrop-filter:blur(22px) saturate(150%);
  -webkit-backdrop-filter:blur(22px) saturate(150%);
  box-shadow:0 8px 32px rgba(0,0,0,.06), inset 0 1px 0 rgba(255,255,255,.6);
}
.dark .glass{
  background:rgba(17,17,19,.55);
  border:1px solid rgba(255,255,255,.09);
  box-shadow:0 8px 32px rgba(0,0,0,.35), inset 0 1px 0 rgba(255,255,255,.07);
}
/* 降级：body.no-glass 时全局关闭 backdrop-filter，退化为实色面板 */
body.no-glass .glass{background:rgba(250,250,250,.98);backdrop-filter:none;-webkit-backdrop-filter:none}
body.no-glass.dark .glass{background:rgba(24,24,27,.98);backdrop-filter:none;-webkit-backdrop-filter:none}
```

**降级策略（评审强制项）**：
1. 运行时 feature flag（`no-glass` class 切换），低端设备/WebView 自动探测关闭
2. 降级后为实色面板（98% 不透明），对比度不降反升
3. 画布内「玻璃卡片」元素导出时自动降级为实色+边框（保真兜底）

### 2.3 字体

| 用途 | 字体栈 |
|---|---|
| UI / 正文 | `Inter`, `-apple-system`, `SF Pro Text`, `PingFang SC`, `Noto Sans SC`, `system-ui` |
| 展示/排版对比 | 衬线展示字体（后续引入，用于画布内标题排版对比） |

### 2.4 圆角 / 阴影 / 间距

| Token | 值 | 用途 |
|---|---|---|
| 圆角 sm | 8px | 输入框 |
| 圆角 md | 12px | 工具按钮、面板角 |
| 圆角 pill | 999px | 导出按钮、缩放胶囊、标签 |
| 阴影玻璃 | 0 8px 32px rgba(0,0,0,.06) | 面板 |
| 阴影画板 | 0 24px 80px rgba(0,0,0,.18) | 画板投影 |
| 间距基准 | 4px 网格（8/12/16/24） | 布局 |

### 2.5 动效

| 场景 | 动效 |
|---|---|
| 面板出现 | fadeIn 0.25s（opacity + translateY 4px） |
| 按钮 hover | 背景 0.15s ease + 按压微缩 |
| 选中框 | 2px 双环描边（白外黑内/暗色反转），z-index 置顶 |
| 原则 | 所有动效 ≤250ms，`prefers-reduced-motion` 时全部关闭 |

## 3. 信息架构与布局

### 3.1 桌面端（主力编辑）—— 三栏 + 顶/底

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部栏 [Logo+名称]   [画板信息]  [缩放 −100%+ 适配] [▩降级][◐主题] [PNG][HTML][ZIP] │
├──────────┬───────────────────────────────────┬───────────────┤
│ 左工具栏 │           画布区 (Viewport)        │  右侧属性面板   │
│ 选择/矩形 │       点阵背景 + 画板 + 图层        │  名称/位置/尺寸  │
│ 圆形/文本 │       空格平移/滚轮缩放/捏合        │  颜色/圆角/文本  │
│ 图片/按钮 │                                   │  透明度/旋转    │
│ ─────── │                                   │               │
│ 复制/删除 │                                   │               │
├──────────┴───────────────────────────────────┴───────────────┤
│ 底部状态栏 [画板 1280×800] [N 个图层]     [Tailwind] [图层快捷标签] │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 移动端（pad/手机）—— 轻编辑 + 浏览

| 区域 | 说明 |
|---|---|
| 顶栏 | 压缩：仅 Logo + 缩放 + 导出（导出按钮收进「⋯」菜单） |
| 左工具栏 | 收为**底部悬浮工具栏**（横向滚动的 icon 条） |
| 属性面板 | 点选元素后**底部弹出抽屉**（半屏），编辑完收起 |
| 画布 | 单指拖画布平移、双指捏合缩放、长按进入元素编辑 |
| 安全区 | `env(safe-area-inset)` 适配刘海/底部手势条，工具栏不被遮挡 |

> pad/手机定位：**轻浏览、轻编辑、分享**。主力编辑回桌面端（评审修正：无 hover/快捷键/面板抢空间，pad 只适合轻任务）。

### 3.3 关键组件规格

| 组件 | 规格 |
|---|---|
| 顶栏高度 | 52px，glass 面板 |
| 左工具栏宽 | 64px（icon 52×~60px 竖排，9px 文字标签） |
| 右属性面板宽 | 240px，可滚动，`space-y-4` |
| 工具按钮 | 52×58px，active 态内阴影描边 + 高亮 |
| 缩放胶囊 | 胶囊形，`− 100% + 适配`，tabular-nums |
| 导出按钮 | PNG/HTML 描边幽灵钮；ZIP 主按钮（反色实心） |
| 属性输入框 | 12px 字号、8px 圆角、深色下白色 7% 底 |
| 属性标签 | 10px 大写字母间距（`.prop-label`） |
| 底部状态栏 | 30px，10px 字号，含图层快捷 chips |

## 4. 页面/关键界面规格

### 4.1 编辑器主界面（核心页面）
- **画布**：点阵背景（24px 网格、1px 圆点）；画板 1280×800 白底 + 投影；缩放 0.1x–4x
- **画板内元素**：`.elm` 绝对定位 + transform 旋转；选中态双环描边
- **画布右下角**：操作提示胶囊（拖拽平移 · Cmd/⌃+滚轮缩放 · 捏合缩放 · 点选编辑）

### 4.2 导出预览
- 导出前确认：文件名、导出类型（PNG 2x / HTML / ZIP）、免费档水印提示
- 导出中：轻量 loading 态（ZIP 打包进度）
- 导出后：下载成功 toast + 完成引导（「导出 HTML 已下载，可双击打开预览」）

### 4.3 模板库（首屏/侧栏）
- 卡片网格：模板缩略图 + 名称 + 标签；悬停「使用此模板」
- v1.0 内置 20+：首页 / 落地页 / 海报 / 作品集

### 4.4 主题切换
- `◐` 按钮：晨（亮）/ 昏（暗）切换，默认**深色主题**（黑白玻璃更出质感）
- `▩` 按钮：毛玻璃降级开关（当前状态可持久化到 localStorage）

## 5. 交互规范

### 5.1 画布手势（对齐 Figma，见 PRD §4.2）

| 操作 | 行为 |
|---|---|
| Ctrl/Cmd+滚轮 | 以鼠标为中心缩放 |
| 滚轮 / 双指 | 平移 |
| 中键 / 空格+拖拽 | 平移 |
| Shift+1 / Shift+0 | 适配画板 / 100% |
| 触控板捏合 | 缩放（锚点=两指中点） |
| 点选元素 | 高亮 + 属性面板联动 |

### 5.2 编辑反馈
- 拖拽元素：实时更新位置（`transform` 驱动，不闪烁）
- 属性修改：`oninput` 即时渲染，数值输入失焦后归一化（clamp 合法范围）
- 删除：有选中元素才可操作；删除后清空选中

### 5.3 状态与空态
| 状态 | 表现 |
|---|---|
| 空画布 | 提示「添加元素或使用模板开始」 |
| 未选中 | 属性面板显示引导文案 |
| 保存中 | 状态栏「已自动保存 HH:mm」 |
| 导出中 | 按钮 loading + 禁用重复点击 |

## 6. 响应式断点

| 断点 | 布局 |
|---|---|
| ≥1024px（桌面） | 三栏完整布局 |
| 768–1023px（pad 横屏） | 三栏，属性面板可折叠 |
| <768px（pad 竖屏/手机） | 底部悬浮工具栏 + 底部属性抽屉 + 顶栏压缩 |
| 折叠屏 344×882 | 同移动端，安全区适配 |

## 7. 可访问性（WCAG）

- [ ] 晨/昏两主题下正文对比度 ≥4.5:1（`--text-secondary` 双模式实测）
- [ ] 键盘可达：工具栏/属性面板 Tab 导航 + 焦点环可见
- [ ] `prefers-reduced-motion` 关闭全部动效
- [ ] 按钮 ≥44px 触控目标（移动端）
- [ ] 语义化：工具栏用 role=toolbar、画板 aria-label

## 8. 视觉验收清单

- [ ] 双主题（晨/昏）切换后无突兀色差，玻璃面板层次清晰
- [ ] 降级开关打开后布局不破、对比度不降反升
- [ ] 4 种导出（PNG/HTML/ZIP）产物与画布视觉一致（含颜色 hex/rgb）
- [ ] 移动端工具栏不遮挡画板、安全区适配正确
- [ ] 拖拽帧率达标（桌面 ≥50fps / 手机 ≥35fps）时无视觉卡顿
- [ ] 点阵背景在缩放各级下无摩尔纹异常

## 9. 与既有原型的关系

`prototype/index.html` 已实现本规范的核心子集（三栏布局、glass 面板、点阵画布、缩放/平移、元素编辑、导出三件套、主题切换、毛玻璃降级开关），可直接作为 UI 实现基线；规范中的断点布局、底部抽屉、模板库卡片网格、导出确认流程需在正式版补齐。
